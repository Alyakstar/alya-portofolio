# Alya Playful Portfolio

A colorful mint-dominant static portfolio website prepared for Vercel.

## Customize before publishing
1. Replace the hero photo placeholder in `index.html`.
2. Replace Instagram, TikTok, and LinkedIn placeholder links with your real profile URLs.
3. Replace Creative Playground placeholders with your own video embeds/files.
4. Edit project descriptions if you want to add screenshots, links, or confidential-safe details.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Deploy to Vercel
### Easiest
1. Unzip this folder.
2. Put the files in a GitHub repository.
3. Sign in to Vercel.
4. Click **Add New → Project**, import the repository, then **Deploy**.
5. Vercel will give you a `*.vercel.app` URL.

Because this is a static HTML/CSS/JS site, no build command is required.
